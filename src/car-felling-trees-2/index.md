## Описание

**Серверный мод**, который позволяет машинам и мотоциклам в DayZ валить деревья при столкновении. 
Настраивается полностью через JSON-конфиг – без правок `config.cpp`.

Мод сам находит весь транспорт в игре (включая добавленный другими модами), добавляет его в конфиг с параметрами по
умолчанию и позволяет включить валку для каждой машины или через базовый класс.

## Основные возможности

- Включение валки для любой машины или мотоцикла через JSON-конфиг – без правки `config.cpp`
- Автоматическое обнаружение всего транспорта (ванильного и из других модов) при старте сервера
- Автоматический сбор доступных слотов для каждой машины
- Наследование параметров по иерархии классов `CfgVehicles` – настройте базовый класс один раз, и все дочерние применят настройки
- Настройка минимальной скорости для валки
- Настройка минимального импульса столкновения
- Проверка заполненности слотов (например, требуется установленный бампер)
- Тиры деревьев – большие деревья требуют тяжёлую технику и высокую скорость
- Ghost-валка («дровосек») – транспорт валит дерево до контакта и едет без отброса
- Логи в отдельный файл с настраиваемым уровнем детализации

## Звук валки (опционально)

Валка деревьев транспортом проходит беззвучно – ванильный DayZ проигрывает звук падения дерева только при рубке топором.

Чтобы игроки слышали, как деревья падают под колёсами, есть опциональный клиентский мод
[MPG_CarFellingTrees2_Client](https://steamcommunity.com/sharedfiles/filedetails/?id=3824417392). Серверу он не нужен,
ставится только игрокам.

## Использование

При первом запуске сервера мод сам создаёт файл с JSON-конфигом, находит весь транспорт (машины и мотоциклы) и
добавляет его в конфиг. После чего вы сможете настроить его так, как вам нужно.
