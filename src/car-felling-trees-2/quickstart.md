# Быстрый старт

Эта страница – для тех, кто ставит мод впервые. Здесь по шагам показано, как за пару минут включить валку деревьев.
Подробное описание каждого параметра – на странице [Конфиг](config.md).

## Шаг 1. Установите мод

::: warning Это серверный мод!
Его нужно ставить только на сервер, на клиент он не нужен.
:::

Установите мод любым привычным способом со Steam:

https://steamcommunity.com/sharedfiles/filedetails/?id=3779032122

## Шаг 2. Запустите сервер – мод создаст конфиг

При первом запуске сервера мод сам создаст конфигурационный файл в папке профиля сервера:

```
<профиль сервера>/
└─ MPG_CarFellingTrees2/
   ├─ Config.json          ← настройки мода и список машин
   └─ Logs/                ← логи мода
```

Папка профиля сервера – это обычно путь, заданный параметром `-profiles=` при запуске сервера. Мод добавляет в неё
подпапку `MPG_CarFellingTrees2/`.

В `Config.json` мод автоматически добавит все найденные машины (ванильные и из других модов) с параметрами по умолчанию
– валка выключена.

## Шаг 3. Включите валку для машины

Откройте `Config.json`, найдите нужную машину в массиве `vehicles` и поставьте `"fellingEnabled": 1`.

Например, включим валку для грузовика:

```json
{
  "className": "Truck_01_Covered",
  "fellingEnabled": 1,
  "slots": ["TruckBattery", "Reflector_1_1", "Reflector_2_1", "Truck_01_Hood"],
  "fellingAttachmentSlots": ["Truck_01_Hood"],
  "fellingMinSpeed": 15.0,
  "fellingMinImpulse": 200.0
}
```

| Параметр                  | Что делает                                                        |
|---------------------------|-------------------------------------------------------------------|
| `className`               | Имя класса машины в `CfgVehicles`                                 |
| `fellingEnabled`          | `-1` наследовать, `0` выключить, `1` включить                     |
| `slots`                   | Доступные слоты машины (собирается автоматически)                 |
| `fellingAttachmentSlots`  | Слоты, которые должны быть заполнены. Пусто – проверка не нужна   |
| `fellingMinSpeed`         | Минимальная скорость (км/ч)                                       |
| `fellingMinImpulse`       | Минимальный импульс столкновения                                  |

Сохраните файл и перезапустите сервер. Теперь при столкновении с деревом на достаточной скорости дерево упадёт.

## Шаг 4. Включите через базовый класс

Не обязательно настраивать каждую машину отдельно. Можно включить валку один раз для базового класса – и все дочерние
машины унаследуют настройку.

Например, `Truck_01_Covered`, `Truck_01_Empty` и другие наследуются от `Truck_01_Base`:

```json
{
  "className": "Truck_01_Base",
  "fellingEnabled": 1,
  "fellingMinSpeed": 15.0,
  "fellingMinImpulse": 200.0
}
```

Все дочерние классы с `fellingEnabled: -1` применят параметры `Truck_01_Base`. Подробнее – в разделе
[Наследование параметров](config.md#наследование-параметров).

## Шаг 5. Смотрите логи

Если что-то не работает – загляните в логи:

```
<профиль сервера>/MPG_CarFellingTrees2/Logs/
```

::: tip Ничего нет в логах?
Поставьте `"logLevel": 1` (TRACE) в `Config.json` – мод начнёт подробно писать, какая проверка валки не прошла
(двигатель выключен, мала скорость, слабый импульс, не дерево и т.п.). Подробнее – в разделе
[logLevel](config.md#loglevel).
:::
